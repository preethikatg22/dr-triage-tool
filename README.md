# dr-triage-tool
"AI-powered diabetic retinopathy triage tool. Grades fundus images (No DR to Proliferative DR) using an EfficientNet-B3 + CORAL ordinal model, fine-tuned on APTOS 2019. Outputs a calibrated confidence score, Grad-CAM heatmap, and a sensitivity-tuned urgent-review flag to prioritize specialist screening. Test QWK: 0.882."
